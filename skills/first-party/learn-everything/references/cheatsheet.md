# 固化阶段 — 把学完的主题压成一页速查表

用户学完一块内容、要复习或长期留存时走这一步。人脑不擅长记长篇大论，但很擅长记**结构**。所以学完别只存一大段聊天记录，把它压成一页——你真正需要的不是重新学一遍，而是在五分钟内把脑子里的结构重新点亮。特别适合考试前、面试前、开会前、做项目前看。

---

## 一页速查表（M4）

**何时用**：某个主题（或子主题）已经学到能讲清、能过考官，要沉淀成可反复调用的复习卡。

**提示模板**：
> 请把《主题》压缩成**一页速查表**，包含以下六块：
> 1. **一句话定义**：这个主题是什么，一句话讲清；
> 2. **最重要的概念**：几个撑起整个主题的核心概念；
> 3. **真实例子**：几个具体、能落地的例子（不是抽象描述）；
> 4. **常见错误**：新手最容易踩的坑；
> 5. **使用前检查清单**：动手前该确认的几件事；
> 6. **五个快速自测题**：能在五分钟内自问自答、验证是否还记得。

**执行 rubric**：
- 六块齐全，**一页为限**——速查表的价值在"一屏扫完"，写成三页就失去了意义。宁可压狠一点，抓最关键的。
- "真实例子"要具体（真实命令、真实场景、真实数字），不能是"比如某种情况"这类占位（呼应源材料反复强调的：留具体、别过度概括）。
- "五个自测题"要能测出真掌握（"遇到 X 你会怎么做、为什么"），不是背定义。
- 术语加中文注释，保证脱离原始对话也能读懂。

**产出物**：一张一页速查表（六块结构）。

---

## 落盘：交给 ob-notes

速查表是本 skill 里**最值得长期留存**的产物——它就是为"日后 5 分钟点亮"而生的。但**本 skill 不自己写盘**：

- 速查表整理好后，主动问用户一句："要把这张速查表存进知识库吗？可以走 ob-notes 沉淀到 Obsidian。"
- 用户要存 → 交给 [[ob-notes]]（它负责 preflight 校验、落点、frontmatter/tag 全套）。速查表这种"学完冻结、反复调用"的结构，天然对应 ob-notes 的**解法卡 / 主题网**呈现。
- 本 skill 只把内容整理成规范的六块结构，**不写项目目录、不自建进度文件、不假装已保存**。职责到"整理好并引导"为止。

学习计划表、学习阶梯图同理：要长期留存 / 逐次打勾，都交给 ob-notes，本 skill 不代管落盘。
