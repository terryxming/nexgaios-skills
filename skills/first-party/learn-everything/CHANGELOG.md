# Changelog

本文件记录 learn-everything 对外版本间的变化（面向使用者），**只记"变了什么"**；为什么这么改、踩了什么坑、否决了什么备选，见 skill 内的 dev-log（面向维护者），此处不复述。

版本遵循语义化版本 `MAJOR.MINOR.PATCH`。

## [0.1.0] - 2026-07-06

首个版本（早期，尚未承诺稳定 API）：帮用户**完整掌握任何知识主题**，以"认知地图自生长"为引擎。

- **引擎**：面向任意主题**自生长**认知地图 + 学习阶梯——结构从主题自身的因果/依赖/层次逻辑长出，**不套预设维度框架**；做到**从整体拆到原子、从原子逆推整体**（`references/cognitive-map.md`）。解决"面对新知识不知从哪开始、只看到零散的点、看不到立体骨架"。
- **六法定序** 1→2→4→5→6→3：认知地图 → 最重要 20% → 一页速查表（学习前的骨架锚点）→ 资源筛选 → 费曼讲解 → AI 考官（`references/focus-and-plan.md`、`references/practice.md`）。
- **触发保守**：只认明确学习意图，或"不知从哪学 / 想要认知地图与学习路径"；一次性"X 是什么"、快速讨论、让 agent 干活均不触发。
- **落盘交 ob-notes**：学习产物（认知地图、学习阶梯、速查表）要长期保存时交给 ob-notes，本 skill 不自己写盘（职责单一）。
- **失败回填通道**（`references/feedback.md`，复用宿主纪律 F / ADR-0012）：真实使用的失败案例先回填成 eval、再改源码——**迭代从使用效果里产生**，未回填不得发布；未配置 `dev_repo` 的环境该通道惰性。
- **认知地图「审查关」**（生成后一律必审）：委派独立子 agent 联网查证官方、按可信度五级（一手权威 / 第三方转译 / 已验证 / 推断 / 待验证）标注，审完整 / 正确 / 清晰 / 结构，据报告修正地图；认知地图宜配图。这是"迭代靠使用效果"的第一个落地。
- **评测**：触发用例 14 正 + 10 负、执行用例 6 条（含"认知地图自生长""对抗套框架""落盘交 ob-notes"）；执行达标验证待随 skill-creator 跑通。
