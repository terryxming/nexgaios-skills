版本遵循语义化版本 `MAJOR.MINOR.PATCH`。

## [0.1.0] - 2026-07-06

首个版本（早期，尚未承诺稳定 API）：把六种学习法组合成一套"系统学会任何主题"的导师式 skill。

- 六法归为**三阶段编排**：建图（学习阶梯 + 资源筛选 + 20 小时计划）、精进（费曼讲解 + AI 考官）、固化（一页速查表），分别下沉到 `references/mapping.md`、`references/practice.md`、`references/cheatsheet.md`。
- 五条铁律：先建图定位不跳级、逼输出先测后教、一次只问一个问题、诚实指出没懂的不表演式鼓励、砍资源而非堆资源。
- 交互模式：**编排导师为主**（按学习阶段主动串联方法）+ **工具箱兜底**（点名单法直达）。
- 触发**保守**：只认明确的"系统学 / 彻底搞懂 / 掌握 / 考我 / 费曼讲 / 做速查表 / 给学习路径"意图；一次性"X 是什么"、快速讨论、让 agent 干活均不触发。
- 学习产物**不自己写盘**，要长期保存时交给 ob-notes 写回 Obsidian（职责单一）。
- 评测：触发用例 12 正 + 11 负、执行用例 4 条；执行达标验证待随 skill-creator 跑通（触发边界已定）。
