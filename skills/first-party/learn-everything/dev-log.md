# learn-everything 开发日志

> [!note] 交接说明
> 本文件是 learn-everything 这个 skill 自身的维护日志（面向维护者），记设计意图、关键决策、踩坑与进展。随 skill 入库并一同分发（ADR-0006），不写用户对外版本叙事——那在 `CHANGELOG.md`。

## 项目意图

帮用户**完整掌握任何知识主题**（不只 AI，也含财务、产品经理等）。核心痛点：面对一个新知识点，人往往**不知从哪开始、只看到零散的局部、看不到立体的骨架**，零散学习效率极低。

解法地基：先按主题**自身逻辑自生长**出一张认知地图 + 学习阶梯（不套预设框架），做到**从整体拆到原子、从原子逆推整体**，让每个点都挂在骨架上；再用六法定序（1→2→4→5→6→3）把主题学透。灵感起点是一段讲"六个学习法"的视频，但真正的 gold standard 是维护者自己 kbase 里已产出的深度学习实录（见决策表）。
