# 写盘前质量自检

**这是写盘前对单篇笔记的最后一道闸**：不合格先修正，别把问题留给未来的自己。本表只判断这一篇是否值得写入 Obsidian，不承担事后复盘或回访统计。

抽取完、套好模板、写盘前，逐项过一遍：


## 1. 30 秒阅读测试（治"没重点"）

第一屏（summary callout）必须让人在 30 秒内拿到这篇的**核心回报**——是什么、解决什么、最重要结论这一层。具体该有哪几栏由 `presentation.md` 的「30 秒读法」规定，本测只查"读者 30 秒内有没有拿到回报"，不在此复列字段。

失败信号：开头先解释文档怎么读、编号体系或内部流程；读完第一屏还不知道收获是什么。


## 2. 信号噪音测试（治"压缩过狠 / 不足"）——复核 distill 分离结果

这是对 `distill.md`（`signal-noise`）分离结果的**写盘前复核**，不重复定义信号 / 噪音——判据与清单以 `distill.md` 为唯一家。查三个方向：

- **漏网的噪音**：笔记里是否还残留操作指令、工具日志、聊天铺垫、同权重的流水尝试？
- **误删的信号**：按 distill 的参照读者判据再扫一遍——确切细节、认知转折、用户的问，有没有被压掉？
- **核心问题与决定**：用户真正要解决的问题、已确认决定与约束是否仍在，不能只剩通用知识。

失败信号："做了什么"多于"学到了什么"；每个步骤权重相同、没有主次；或笔记回答了另一个更泛的问题。命中即回 `distill.md` 重新分离，并对照 `anti-patterns.md`。


## 3. 证据与漂移测试（治"伪知识 / 二次生成漂移"）

拿内部证据账本逐条反查成文结果。每项都必须通过：

- **结论有源**：每条重要结论都带来源脚注，脚注含来源时间、对话轮次与足以支撑结论的证据片段；来源时间缺失就写「时间未记录」，不补造。
- **没有无源新增**：笔记没有来源中找不到的新事实、新因果或扩大后的决定。
- **确定性不升级**：`可能` / `推测` / `待验证` 没有被写成 `一定` / `已证实`；可信度与证据强度匹配。
- **限制不丢失**：否定、条件、前提、例外、适用边界没有在提炼中消失。
- **受保护原子一致**：用户决定与约束、命令、代码、配置、报错、数字、日期、版本、路径、字段 / API / 参数名与来源一致。
- **显式逐字模式真逐字**：用户要求问答实录、不要压缩或原样保留时，问与答来自 transcript；除已声明滤掉的噪音外，不改写、不冒充原话。

没有亲验的，不写成确定结论——按 `credibility-spec` 标 `[待验证]`，必要时放进「适用边界 / 待验证」。外部事实无一手出处时，不写成事实（配合 frontmatter 的 `source_url`）。

失败信号：脚注只写「来自对话」却没有时间与证据片段；结论比来源更强；精确值被近似；条件句被写成无条件规则。


## 4. 复用测试（治"只能回忆、不能指导"）

明确"**下次遇到什么情况**用这篇"，给出检查清单、判断准则或可迁移模式，让未来的你或 agent 少走一步弯路。

失败信号：看完不知道如何行动；只能回忆历史。


## 5. 掌握测试（治"只记录、未掌握"）—— 仅主题网（持续生长）笔记

读起来像作者**真的掌握了**，还是只是把资料复述了一遍？掌握的标志：讲得清（三五句能教会外行）、判得明（说得出边界与偏见）、用得上、迁得动（看得出能用到别处）。

失败信号：通篇是"原文说了 A、B、C"的转述，没有作者自己的消化、判断与迁移；读完只多了信息，没多出"会用"。

注：本测试只对主题网（持续生长）笔记适用；它考的是"掌握的功力有没有透出来"，**不要求笔记里有"复述""迁移"等章节**（方法论不上台面，见 `presentation.md` 的 `mastery-lens`）。


## 6. 格式合规测试（治"格式跑偏"）

落盘前对照 `frontmatter-tags.md` 与输出不变量核一遍形式，这是写完的最后一道形式关（格式规则的唯一家是 `frontmatter-tags`，本测只核"照它做没有"、不复述其内容）：

- **frontmatter 齐全**：title / date / updated / source / 三轴 tags（`frontmatter-spec`、`tag-system`），无 read_count / last_read 等已废字段。
- **文件名 = 标题**：正文不写 H1，避免双标题（`naming-rule`）。
- **30 秒读法综合头在位**：六栏齐全（是什么 / 背景 / 解决什么 / 最重要结论 / 怎么用 / 前置；主题网另加边界），最重要结论带可信度与来源脚注。
- **来源脚注合规**：重要结论脚注按 `linking-convention` 写来源时间、轮次与证据片段；笔记生命周期时间没有冒充来源时间。
- **排版克制**：每 markdown 元素一职责、段落优先、同屏常开 callout 不超载（`layout-rule`）。

失败信号：frontmatter 缺字段或带废字段、正文出现 H1 双标题、无 30 秒读法头、版式炫技。命中即回各自唯一家（`frontmatter-tags`）补齐再写。


## 最低合格线

一篇正式落盘，至少要过这几关：

- 四项必过：30 秒阅读、信号噪音、证据、格式合规；
- 若材料是网页/长文/报告，另过 `distill.md` 的 `source-fidelity`（原文结构覆盖）；
- 主题网（持续生长）笔记，另过掌握测试。

任一不过，先修正再写盘。
