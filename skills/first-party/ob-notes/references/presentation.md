# 呈现侧重 — 蒸馏出的信号，按复用目标摆成笔记

信号 / 噪音分离与证据账本（见 `distill.md`）已决定**记什么、依据是什么、哪些字面信息不能变**。这一步只做一件事：按复用目标把账本里的信息组织成笔记，不重判来源。

守住同一个不变量：每篇都有 30 秒读法、结构化正文与来源脚注；重要结论带可信度和来源脚注，脚注带来源时间。三种呈现的差别是保真级别与正文结构。

按 `SKILL.md` 的 `mode-decision`（「未来最想复用什么」）选一种，不在入口强制三选一：

- 复用**追问路径本身** → 追问链：问与答逐字按**轮次**铺开。
- 复用**一条解法** → 解法卡：忠实提炼为**现象 → 根因 → 解法**，受保护原子逐字。
- 复用**一个要长期养的主题** → 主题网：跨轮次忠实整合为**内容结构**，不套固定骨架。

前两种编排结构由**形式**定（对话逐轮、现象 → 解法），稳定；主题网编排由**内容**定，一主题一个样。遇交叉不硬切：选一个主侧重，另一侧用 `[[双链]]` 回指缝合。格式细节（frontmatter、tag、可信度、日期、命名、排版）遵循 `frontmatter-tags.md`。文件名即标题，正文不写 H1。


## 追问链（问答实录）

当连续追问本身有复用价值（理解路径比单个结论更重要），或用户明确要求问答实录、不要压缩、原样保留时，用追问链。保留提问链、逐轮问答；**问与答均从会话 transcript 逐字扣**（规则项 `transcript-extract`，见 `distill.md`；普通整理可滤操作旁白，用户要求完整逐字时连同旁白原样保留）。下面给骨架与排版纪律。标题按 `{{主题}}：问答实录.md`。

```markdown
---
```

排版纪律（追问链专属）：

- **每轮收口一句总纲**：每轮末尾给一句可带走的判断/公式/对比（附加在逐字答之外的导航句，不改动扣出的原文）；30 秒读法的“最重要结论”应能直接从各轮总纲中摘出。收不出总纲的轮次，说明该轮没有独立的认知增量——考虑并入相邻轮。
- **轮次标题服务阅读**：用 `〔第一轮提问：...〕` 标出追问层次，不把每一轮压成同权重流水账。
- **不要把问答改成 FAQ**：FAQ 会打散原始追问顺序；价值在于保留理解如何推进。
- **结论仍要可复用**：末尾必须有小结 / 下次怎么用 / 生长钩子之一，避免只剩聊天记录。

## 主题网（研究）

当主题会反复回来深挖、长期追加、值得织进知识网时，用主题网。一主题一笔记。

**不要给主题网套固定章节骨架。** 让结构由**主题自身的逻辑**决定——三个并列的最佳实践、一个概念的演化、多方案对比，自然结构各不相同。预设「是什么 / 为什么 / 关键点」这类格子会削足适履：打碎内容的真实结构、塞进不合身的格子，还诱导每格均匀填浅；它更和 `source-fidelity` 直接打架——后者要保留原文结构，固定骨架却用预设结构覆盖它。

所以只固定主题网的**入口层**，正文放手让内容自己长：

**固定的入口层**（检索/扫读用，不限制正文怎么展开）：

```markdown
---
title: {{主题名}}
date: {{创建日 YYYY-MM-DD}}
updated: {{最后更新日}}
source: {{来源 agent/任务}}
source_url: {{一手出处，有就填}}
tags: [类型/研究, 可信/待验证, 状态/持续]
---

> [!summary] 30 秒读法
> - **是什么**：{{本质一句}}
> - **背景**：{{为什么养这个主题——起于什么困惑 / 需求}}
> - **解决什么**：{{针对什么问题}}
> - **最重要结论**：{{最该带走的判断，1–3 条}} `[可信度]` [^s1]
> - **怎么用**：{{怎么落地复用}}
> - **前置**：{{要先懂什么；没有就省}}
> - **边界**：{{能做/做不了，能力速览（非可信度）}}
```

**放手的正文——按证据忠实整合**：从证据账本出发，把多轮内容合并、去重复、排序和改写成更清楚的主题讲解。用最忠实承载主题的结构去写——有清晰的三段实践就分三节、是概念演化就按时间线、是多方案对比就上对比维度。标题层级、小节命名都服从**内容**、不服从模板。受保护原子保持原样，重要结论加来源脚注；不同来源有冲突时保留分歧和时间，不强行揉成一致。跨会话深挖时，把新结论追加进对应小节并带日期，主题网就是这样一层层长厚的。

写作守三条纪律（顺序即优先级）：

1. **求深（`mastery-lens`，首要）**：先过下面的掌握视角四问，用它筛选证据、组织解释；宁可把钻透一个点写清楚，不要全景铺一堆浅结论。对话里没吃透的，标成待深挖钩子，不臆造。
2. **保真（`source-fidelity`）**：含外部材料时，按 `distill.md` 的 `source-fidelity` 保留原文结构与机制，别压成观点卡——这正是固定骨架会毁掉、而放手能保住的东西。
3. **防腐化（持续生长）**：追加带日期、推翻旧结论用删除线留痕不删（`datestamp-rule`）、相关主题建 `[[双链]]`（`linking-convention`）、诚实标“我的疑问/待验证”当深挖钩子。第一次浅不要紧，主题网靠持续追加变深。

**增量优先于新建（写盘前必做，不是可选）**：落盘前**先在 `{kb_root}` 按主题名搜一次**（`naming-rule` 的主题命名就是为此），命中同主题笔记就追加到对应处并带日期，没有才新建，避免同一主题攒出多篇碎片。注意：这步执行力依赖 agent 真去搜，规范只能下令、保障要靠 eval 盯（当前 `[试行待验证]`）。

**可选的组织参考**（不是模板，是「别人常这么摆」，**照搬即错**）：概念型常见「本质 → 为什么这样 → 边界 → 怎么用」，对比型常见「维度表 + 各方案机制」，演化型常按时间线。按你的主题取舍。


### 掌握视角（`mastery-lens`，主题网专属）

主题网的目标不是“记下我读过什么”，而是“让未来的我真正掌握这个主题”。掌握不是“我知道这个概念”，而是我能**解释它、判断它、应用它、迁移它**。成文前用这几个问题自检——答得出，就用来源支持的内容写清；答不出，说明对话里还没吃透，标成待深挖钩子，别补造来源没有的答案：

- **能讲清吗**：三五句话能讲给一个外行听懂吗？（讲不清＝没真懂）
- **何时不成立**：它的边界、前提、偏见在哪？
- **能迁到哪**：除了眼前这个场景，这套思路还能用在别处吗？
- **连得上谁**：它和我已有的哪篇笔记相关？

> [!warning] 这是取材与组织的内功，不是笔记的骨架
> 上面四问是**作者的思考纪律，绝不能变成笔记里的固定章节**（如“## 复述”“## 迁移”）。把方法论摆成标题，会诱导为填空而填空、还把整合好的理解又切碎了。掌握应从**取什么证据、如何组织解释**透出来：保留暴露误解的纠错证据、先讲机制再下结论、建立真实双链，而不是贴标签或补造来源没有的答案。
